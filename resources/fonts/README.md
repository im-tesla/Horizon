Inter is bundled for native playback controls and text subtitles. No system font
installation or font download is needed when using Horizon.

`Inter.ttf` is the Inter variable TrueType font from the official Google Fonts
repository: https://github.com/google/fonts/tree/main/ofl/inter.
The accompanying `OFL.txt` contains its SIL Open Font License 1.1.

Subtitle appearance also offers Noto Serif and Noto Sans Mono. Their variable
TrueType fonts are bundled for identical choices on Windows and Linux; no system
font installation is needed. Sources are the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notoserif and
https://github.com/google/fonts/tree/main/ofl/notosansmono.
Both are licensed under the SIL Open Font License 1.1 in `Noto-OFL.txt`.
